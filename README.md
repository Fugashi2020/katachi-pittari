# かたちぴったり

1歳半〜2歳向けの、あそびを集めたアプリです。
ブラウザだけで動きます。ビルド不要、依存ライブラリなし。

現在5本のあそびが入っています。

## 収録しているあそび

### かたちぴったり

あなに合う形をタップすると、ピースが飛んでいってはまります。

- **ドラッグを使わない** — タップすると自動で穴へ飛びます。1歳半ではドラッグ操作がまだ難しいためです
- **まちがいがない** — 形が合わなければ穴の縁でぽよんと跳ねて戻るだけ。否定音も減点もありません
- **固まらない** — 7秒さわらないと、正解のピースがぷるぷる揺れて教えます
- 5個そろうと紙吹雪が出て、そのまま次に進みます

### はこんで ぴったり（2歳むけ）

かたちぴったりの**ドラッグ版**です。ピースを指でつまんで、穴まで運びます。

- **ドラッグは2歳の節目** — タップしかできなかった子が運べるようになる時期なので、1歳半版と並べておくと成長が目に見えます
- **穴の近くで吸い込む** — 2歳はぴったり重ねられないため、穴の幅の0.65倍（半径の1.3倍）まで近づけば入ったことにします
- **近づくと穴が開く** — 穴が少し大きくなって白い枠が出るので、「ここに入る」が目で分かります
- **途中で離すと元に戻る** — 中途半端な位置に残すと、次にどうすればいいか分からなくなるためです
- 形が違うときは、穴がぷるっと揺れてピースが戻るだけ。否定しません
- うまくいかない日は、タップ版（かたちぴったり）に戻れます

形の定義は かたちぴったり と共有しているので（`art.js` の `KP.SHAPES`）、
形を足すと両方に増えます。

### いないいないばあ

ぬのをタップするとめくれて、中から動物が出てきます。

- **失敗が存在しない** — さわれば必ず何かが起きる、因果応答そのものの遊びです
- 出てきた動物をさわると、もう一度鳴きます
- しばらく放っておくと、ぬのが大きく揺れて誘います
- 12種類（動物8＋のりもの4）と、ぬの7色をランダムに組み合わせます。同じものが連続しません

「隠れても存在し続ける」という理解が育つ時期に合わせた内容です。

### どれかな

「わんわん、どれかな？」と音声で言われたものを、並んだ絵の中から選びます。

- **聞いて選ぶ** — 1歳半は「話す」より「聞いて分かる」が先に育つので、この月齢に合っています
- **レベルで枚数が変わる** — レベル1で2枚、レベル5で6枚。保護者メニューで切り替えます
- **呼びかけは幼児語** — 「わんわん、どれかな？」と聞き、正解すると「いぬ だね」と正式な名前も教えます
- **まちがいがない** — 違う絵はぷるっと揺れるだけ。2回外すと正解が揺れて、もう一度読み上げます
- 上のボタンを押すと、お題をもう一度読み上げます（親が押す想定です）

### ぱちんと

ゆっくり浮かんでくるシャボン玉を、タップで割ります。

- **おおきく・ゆっくり** — 1歳半は速い動きを追えないため、画面を14〜21秒かけて昇ります。大きさも画面の短辺の1/4前後を確保しています
- **失敗がない** — 割れなければ上まで行って消え、次が出てくるだけです
- **手と目の協応** — 止まっているものではなく動くものを狙うので、他の3本にない運動の要素があります
- 割った場所から粒が飛び散ります（`KP.burst()`）。5個割るごとに紙吹雪
- 連打する遊びなので、1個ごとには褒めません

## 共通の設計方針

- **文字を読ませない** — 説明は音と読み上げ（Web Speech API）で行います
- **終わりがない** — ゲームオーバーもタイムアップもありません。飽きたら親が止める前提です
- **誤操作させない** — 画面固定・ホーム画面起動を前提にし、保護者メニューは長押しでしか開きません

## おうちのかたメニュー

画面右上の小さな丸を **1.2秒長押し** すると開きます。子供が偶然開かない長さにしてあります。

- 効果音のオン／オフ
- 読み上げのオン／オフ
- ピースの数（2〜4個）— かたちぴったり と はこんでぴったり。1歳半ならまず2個から
- レベル（1〜5）— どれかなのみ。レベル1で絵2枚、レベル5で6枚
- 今日できた回数（あそび別）
- おうちに戻る

## プライバシー

- 外部への送信は一切ありません
- 設定と記録は端末内の `localStorage` のみに保存されます
- 外部から読み込むのは Google Fonts の書体だけです

## スマホで遊ぶとき

ブラウザで開いたあと、**ホーム画面に追加**してください。

- iPhone / iPad — 共有ボタン →「ホーム画面に追加」
- Android — Chrome のメニュー →「アプリをインストール」

アドレスバーとタブが消えるので、遊んでいる途中で別のページへ飛ぶ事故がなくなります。
さらに iOS の「アクセスガイド」／Android の「アプリ固定」を併用すると、ホームにも戻れなくなります。

一度開けばオフラインでも遊べます（Service Worker）。

## 公開方法（GitHub Pages）

Settings → Pages → Source を **Deploy from a branch**、Branch を **main / (root)**。
`https://fugashi2020.github.io/katachi-pittari/` で公開されます。

## 更新するとき

編集して push すれば反映されます。アプリ内のファイルはすべてネットワーク優先で
取得する設定なので、**キャッシュ名を手で上げなくても更新は端末に届きます**。

`sw.js` の `CACHE` を上げるのは、**ためておくファイルを増やしたとき**（`ASSETS` に
行を足したとき）だけです。

### なぜネットワーク優先なのか

GitHub Pages は10分間のキャッシュ指定を付けて配信します。さらに Service Worker を
キャッシュ優先にすると、**修正しても古いファイルが使われ続け、原因が極めて分かり
にくくなります**（実際に一度踏みました）。そのため、

- 自分のファイル（HTML・JS・アイコン）… `cache: "no-store"` でネットワーク優先。
  つながらないときだけキャッシュから出す（オフラインでも遊べる）
- Google Fonts の書体だけ … 変わらないのでキャッシュ優先

としています。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の器。共通CSS、おうち画面、各あそびの入れ物、保護者メニュー |
| `app.js` | 共通の土台。設定の保存、音、読み上げ、ほめことば、紙吹雪、画面の切り替え |
| `art.js` | 絵と形のライブラリ。絵18種（いないいないばあ・どれかな）と形5種（かたはめ2本）を共有 |
| `game-katachi.js` | かたちぴったり（タップ） |
| `game-hakobu.js` | はこんで ぴったり（ドラッグ・2歳むけ） |
| `game-baa.js` | いないいないばあ |
| `game-doreka.js` | どれかな |
| `game-pachin.js` | ぱちんと |
| `sw.js` | オフライン用のキャッシュ制御 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・起動設定 |
| `icon-180/192/512.png` | アプリアイコン |

形も動物も SVG、効果音は Web Audio API での合成なので、画像・音声の素材ファイルはありません。

## 絵を足すとき

`art.js` の `KP.ART` に1件足すだけです。いないいないばあ（`animal` と `vehicle`）と
どれかな（全グループ）の両方に自動で出るようになります。

```js
{ id:"panda", name:"ぱんだ", call:"ぱんだ", voice:"ぱんだ", group:"animal", svg: "..." }
```

`svg` は `viewBox="0 0 100 100"` の中身だけを書きます。動物は丸い顔に耳や鼻を足す
同じ骨格で描くと、並んだときに揃って見えます。

## あそびを足すとき

1. `game-<名前>.js` を作り、末尾で土台に登録する

   ```js
   KP.register("<id>", {
     start:   function(){ /* 画面を組み立てる */ },
     stop:    function(){ /* タイマーを止める */ },
     restart: function(){ /* 設定変更後に組み直す */ }
   });
   ```

   `KP.snd` / `KP.say()` / `KP.cheer()` / `KP.confetti()` / `KP.count()` が土台から使えます。

2. `index.html` に `<div id="screen-<id>" class="screen" hidden>` を足し、
   おうち画面のタイルに `data-game="<id>"` を付ける
3. `<script src="game-<名前>.js">` を読み込む
4. `sw.js` の `ASSETS` にファイルを足して `CACHE` の番号を上げる
