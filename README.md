# かたちぴったり

1歳半〜2歳向けの、かたちあそび（型はめ）ゲームです。
ブラウザだけで動きます。ビルド不要、依存ライブラリなし。

## 設計の方針

この月齢に合わせて、一般的なパズルゲームとは違う作りにしています。

- **ドラッグを使わない** — タップすると、ピースが自動で穴へ飛びます。1歳半ではドラッグ操作がまだ難しいためです。
- **まちがいがない** — 形が合わなければ穴の縁でぽよんと跳ねて戻るだけ。否定音も減点もありません。
- **終わりがない** — ゲームオーバーもタイムアップもなし。5個そろうと紙吹雪が出て、そのまま次に進みます。
- **固まらない** — 7秒さわらないと、正解のピースがぷるぷる揺れて教えます。
- **文字を読ませない** — 説明は音と読み上げ（Web Speech API）で行います。

## おうちのかたメニュー

画面右上の小さな丸を **1.2秒長押し** すると開きます。子供が偶然開かない長さにしてあります。

- 効果音のオン／オフ
- 形の読み上げのオン／オフ
- ピースの数（2〜4個）— 1歳半ならまず2個から
- 今日ぴったりできた回数

## プライバシー

- 外部への送信は一切ありません。
- 設定と記録は端末内の `localStorage` のみに保存されます。
- 外部から読み込むのは Google Fonts の書体だけです。

## スマホで遊ぶとき

ブラウザで開いたあと、**ホーム画面に追加**してください。

- iPhone / iPad — 共有ボタン →「ホーム画面に追加」
- Android — Chrome のメニュー →「アプリをインストール」

アドレスバーとタブが消えるので、遊んでいる途中で別のページへ飛ぶ事故がなくなります。
さらに iOS の「アクセスガイド」／Android の「アプリ固定」を併用すると、ホームにも戻れなくなります。

一度開けばオフラインでも遊べます（Service Worker）。

## 公開方法（GitHub Pages）

1. このリポジトリを GitHub に push
2. Settings → Pages → Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
3. 1〜2分待つと `https://<ユーザー名>.github.io/katachi-pittari/` で公開されます

## 更新するとき

`index.html` を編集して push すれば反映されます。
ページ本体はネットワーク優先で取得する設定なので、リロードすれば新しい画面になります。

アイコンや `manifest.webmanifest` を差し替えたときだけ、`sw.js` の `CACHE` の番号を
（`kp-v1` → `kp-v2` のように）上げてください。古いキャッシュが破棄されます。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | ゲーム本体。HTML・CSS・JavaScript がすべてこの1枚に入っています |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・起動設定 |
| `sw.js` | オフライン用のキャッシュ制御 |
| `icon-180/192/512.png` | アプリアイコン |

形は SVG、効果音は Web Audio API での合成なので、画像・音声の素材ファイルはありません。
