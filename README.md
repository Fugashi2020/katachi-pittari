# かたちぴったり

1歳半〜2歳向けの、あそびを集めたアプリです。
ブラウザだけで動きます。ビルド不要、依存ライブラリなし。

現在2本のあそびが入っています。

## 収録しているあそび

### かたちぴったり

あなに合う形をタップすると、ピースが飛んでいってはまります。

- **ドラッグを使わない** — タップすると自動で穴へ飛びます。1歳半ではドラッグ操作がまだ難しいためです
- **まちがいがない** — 形が合わなければ穴の縁でぽよんと跳ねて戻るだけ。否定音も減点もありません
- **固まらない** — 7秒さわらないと、正解のピースがぷるぷる揺れて教えます
- 5個そろうと紙吹雪が出て、そのまま次に進みます

### いないいないばあ

ぬのをタップするとめくれて、中から動物が出てきます。

- **失敗が存在しない** — さわれば必ず何かが起きる、因果応答そのものの遊びです
- 出てきた動物をさわると、もう一度鳴きます
- しばらく放っておくと、ぬのが大きく揺れて誘います
- 動物8種類（いぬ・ねこ・うさぎ・ぞう・ぶた・くま・ひよこ・かえる）と、ぬの7色をランダムに組み合わせます

「隠れても存在し続ける」という理解が育つ時期に合わせた内容です。

## 共通の設計方針

- **文字を読ませない** — 説明は音と読み上げ（Web Speech API）で行います
- **終わりがない** — ゲームオーバーもタイムアップもありません。飽きたら親が止める前提です
- **誤操作させない** — 画面固定・ホーム画面起動を前提にし、保護者メニューは長押しでしか開きません

## おうちのかたメニュー

画面右上の小さな丸を **1.2秒長押し** すると開きます。子供が偶然開かない長さにしてあります。

- 効果音のオン／オフ
- 読み上げのオン／オフ
- ピースの数（2〜4個）— かたちぴったりのみ。1歳半ならまず2個から
- 今日できた回数（あそび別）
- おうちに戻る

## プライバシー

- 外部への送信は一切ありません
- 設定と記録は端末内の `localStorage` のみに保存されます
- 外部から読み込むのは Google Fonts の書体だけです

## スマホで遊ぶとき

ブラウザで開いたあと、**ホーム画面に追加**してください。

- iPhone / iPad — 共有ボタン →「ホーム画面に追加」
- Android — Chrome のメニュー →「アプリをインストール」

アドレスバーとタブが消えるので、遊んでいる途中で別のページへ飛ぶ事故がなくなります。
さらに iOS の「アクセスガイド」／Android の「アプリ固定」を併用すると、ホームにも戻れなくなります。

一度開けばオフラインでも遊べます（Service Worker）。

## 公開方法（GitHub Pages）

Settings → Pages → Source を **Deploy from a branch**、Branch を **main / (root)**。
`https://fugashi2020.github.io/katachi-pittari/` で公開されます。

## 更新するとき

編集して push すれば反映されます。ページ本体はネットワーク優先で取得する設定です。

**ファイルを追加・削除したときは、`sw.js` の `ASSETS` に反映し、`CACHE` の番号を
（`kp-v3` → `kp-v4` のように）上げてください。** 上げないと、古いファイル一覧のまま
キャッシュが残り続けます。

GitHub Pages は HTML に10分間のキャッシュ指定を付けて配信します。そのままだと
更新が端末に届かないため、`sw.js` の取得に `cache: "no-store"` を指定しています。

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の器。共通CSS、おうち画面、各あそびの入れ物、保護者メニュー |
| `app.js` | 共通の土台。設定の保存、音、読み上げ、ほめことば、紙吹雪、画面の切り替え |
| `game-katachi.js` | かたちぴったり |
| `game-baa.js` | いないいないばあ |
| `sw.js` | オフライン用のキャッシュ制御 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・起動設定 |
| `icon-180/192/512.png` | アプリアイコン |

形も動物も SVG、効果音は Web Audio API での合成なので、画像・音声の素材ファイルはありません。

## あそびを足すとき

1. `game-<名前>.js` を作り、末尾で土台に登録する

   ```js
   KP.register("<id>", {
     start:   function(){ /* 画面を組み立てる */ },
     stop:    function(){ /* タイマーを止める */ },
     restart: function(){ /* 設定変更後に組み直す */ }
   });
   ```

   `KP.snd` / `KP.say()` / `KP.cheer()` / `KP.confetti()` / `KP.count()` が土台から使えます。

2. `index.html` に `<div id="screen-<id>" class="screen" hidden>` を足し、
   おうち画面のタイルに `data-game="<id>"` を付ける
3. `<script src="game-<名前>.js">` を読み込む
4. `sw.js` の `ASSETS` にファイルを足して `CACHE` の番号を上げる
